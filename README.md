# Корпоративная информационная система управления производственными активами c реализацией отказоустойчивого кластера баз данных (EAM-система)

Дипломный проект (ВКР), посвященный разработке корпоративной информационной системы для автоматизации процессов учёта, технического обслуживания и ремонта (ТОиР) производственного оборудования.

## О проекте

Система предназначена для замены разрозненных инструментов учёта (электронных таблиц, бумажных журналов) на единое информационное пространство. Основные бизнес-процессы, автоматизируемые системой:
- Ведение реестра и паспортизация оборудования.
- Подача и обработка заявок на ремонт.
- Создание и выполнение нарядов на работы.
- Учёт запасных частей.
- Формирование аналитической отчётности.
- Интеграция с внешним сервисом мониторинга состояния инфраструктуры.

## Технологический стек

**Backend:**
- Язык: Java 17 (LTS)
- Фреймворк: Spring Boot 3
- Безопасность: Spring Security + JWT (JSON Web Tokens)
- База данных: PostgreSQL 18
- Работа с БД: Spring Data JPA, Hibernate, Flyway (миграции)
- Документация API: SpringDoc OpenAPI (Swagger UI)

**Frontend:**
- Язык: TypeScript
- Фреймворк: Vue 3 (Composition API)
- Сборщик: Vite
- Маршрутизация: Vue Router
- Управление состоянием: Pinia
- HTTP-клиент: Axios
- Иконки: SVG-компоненты (через `vite-svg-loader`)

**Инфраструктура (Отказоустойчивость):**
- Контейнеризация: Docker, Docker Compose
- Кластер СУБД: PostgreSQL (3 узла), Patroni (управление), etcd (хранилище состояния), HAProxy (балансировка).

## Развёртывание проекта (Локальный запуск)

### 1. Запуск отказоустойчивого кластера БД

Кластер разворачивается одной командой. Перейдите в директорию `database` и выполните:

```bash
cd database
docker compose up -d
```
*Система поднимет 3 узла PostgreSQL, 3 узла etcd, Patroni и HAProxy. Подключение к БД (Primary) осуществляется через HAProxy на порту `5000`.*

### 2. Запуск Backend (Spring Boot)

Перейдите в директорию `backend`. Убедитесь, что в `application.properties` указан корректный URL к HAProxy (`jdbc:postgresql://localhost:5000/eam_database`).

```bash
cd backend
./mvnw spring-boot:run
```
*API будет доступно по адресу `http://localhost:8080`. Документация Swagger UI: `http://localhost:8080/swagger-ui.html`.*

### 3. Запуск Frontend (Vue 3)

Перейдите в директорию `frontend`, установите зависимости и запустите dev-сервер:

```bash
cd frontend
npm install
npm run dev
```
*Интерфейс будет доступен по адресу `http://localhost:5173`.*

## Реализованный функционал (Frontend MVP)

На данный момент реализован интерфейс, работающий на mock-данных (сервисный слой готов к замене на реальные REST-запросы):
- **Дашборд:** с ролевыми KPI-карточками, лентой событий и состоянием системы.
- **Активы:** таблица с фильтрацией, поиском и пагинацией.
- **Заявки:** список с разделением прав (автор видит только свои заявки).
- **Наряды:** разделение на представление Мастера (все наряды) и Механика (только свои).
- **Запчасти:** справочник с индикацией остатков.
- **Авторизация:** страница входа с ролевой моделью (заглушка).

## Ролевая модель

В системе реализовано 4 роли:
- **ADMIN** (Администратор) — полный доступ, управление справочниками и пользователями.
- **MASTER** (Мастер) — управление заявками и нарядами, контроль работы.
- **TECHNICIAN** (Механик) — выполнение назначенных нарядов.
- **REQUESTER** (Заявитель) — подача заявок на ремонт, отслеживание их статуса.
