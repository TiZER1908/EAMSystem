# Матрица доступа

Матрица доступа определяет, какая роль имеет доступ к какой функции системы. Дополняет документ «Функциональные требования»: в ФТ описано, **что** система должна делать, в матрице — **кому** это разрешено.

## Обозначения

| Символ | Значение |
|---|---|
| ✓ | Действие разрешено |
| ✗ | Действие запрещено |
| ◐ | Частичный доступ (только свои объекты или только просмотр) |

## Роли

| Код | Роль | Описание |
|---|---|---|
| ADMIN | Администратор | Сотрудник ИТ-службы, полный доступ |
| MASTER | Мастер | Руководитель ремонтной службы |
| TECHNICIAN | Механик | Сотрудник ремонтной службы |
| REQUESTER | Заявитель | Любой сотрудник предприятия |
