# Функциональные требования

Функциональные требования определяют основные возможности системы. Каждое требование сформулировано в соответствии с принципами атомарности (описывает одно действие), однозначности (не допускает разных толкований) и проверяемости (может быть проверено тестированием).

Субъектом требования выступает Система. Роли пользователей указываются как условие выполнения («Система должна предоставлять [кому] возможность…»).

## Обозначения

- **FR** — Functional Requirement (функциональное требование)
- **[МОДУЛЬ]** — код функционального модуля
- **[НОМЕР]** — порядковый номер внутри модуля
